# Smart Resume Screener

An AI-powered resume screening system that extracts structured candidate information and evaluates candidate-job fit using an LLM.

## Project Status

🚧 Under development

## Tech Stack

- Python
- FastAPI
- SQLite
- LLM API

## Core Features

- Resume PDF/text processing
- Structured resume information extraction
- Job description processing
- Semantic candidate-job matching
- Candidate scoring and ranking
- Match justification
